# Contributing to Notes-Builder

Thank you for your interest in contributing to **Notes-Builder**! 🎓

Notes-Builder aims to provide **clear, accurate, well-structured, and high-retention study notes** for students and competitive-exam aspirants.

Whether you want to fix a factual error, improve an explanation, add a new topic, or improve the website, your contribution is welcome.

Please read this guide before opening an issue or submitting a Pull Request.

## 🤝 Code of Conduct

Please keep contributions and discussions respectful and constructive.

Contributors are expected to:

- Be respectful to other contributors.
- Provide constructive feedback.
- Focus on accuracy and clarity.
- Avoid unsupported factual claims.
- Keep discussions relevant to the project.
- Respect different approaches and opinions.

## 🚀 Ways to Contribute

There are several ways you can contribute to Notes-Builder:

### 🐛 Fix Errors

You can help by identifying and fixing:

- Typographical errors
- Incorrect dates
- Incorrect historical facts
- Incorrect constitutional provisions
- Mathematical errors
- Broken links
- Incorrect current-affairs information
- Formatting problems

### 📚 Add New Notes

You can contribute notes for topics such as:

- Ancient History
- Medieval History
- Modern History
- Indian Polity
- Geography
- Indian Economy
- Environment & Ecology
- Science & Technology
- International Relations
- Andhra Pradesh
- Current Affairs
- Other UPSC/APPSC-related topics

### 🎨 Improve the Website

You can also contribute improvements to:

- HTML
- CSS
- JavaScript
- Navigation
- Accessibility
- Responsive design
- User experience
- Page performance

## 🐛 Reporting Bugs

If you find an error, please open a **GitHub Issue**.

When reporting an issue, provide as much useful information as possible.

### For content-related issues

Please include:

- File name
- Section or heading
- Existing incorrect information
- Correct information
- Reliable source/reference

### Example

```text
File: notes/indian-polity/article-18.html

Section: Fundamental Rights

Issue:
Article 18(2) is incorrectly described as allowing Presidential permission.

Correction:
Article 18(2) contains no provision for Presidential permission
for an Indian citizen accepting a title from a foreign State.

Reference:
Constitution of India, Article 18(2)
